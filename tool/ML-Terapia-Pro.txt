## 7. WORKFLOW DE TRABALHO (COMO A GENTE TRABALHA JUNTO)

### Padrão: Python que aplica patch em HTML

**NUNCA editar arquivo grande manualmente.** Sempre:
1. Eu escrevo um **script Python** que aplica a mudança
2. O script faz **backup** em `_backups/` antes
3. O script **loga** cada passo com ✅/❌
4. O script é **idempotente** (rodar 2x não quebra)
5. Leandro roda: `pp apply_xyz.py` (não usa `python3` puro)

**Template mental do script:**

```python
#!/usr/bin/env python3
import re, sys, shutil
from datetime import datetime
from pathlib import Path

ROOT = Path("/Users/leandrogrocha/Documents/DEV/MARILAND/ml-projeto")
TARGET = ROOT / "dashboard-v2.html"
BACKUP_DIR = ROOT / "_backups"

def backup(p):
    BACKUP_DIR.mkdir(exist_ok=True)
    stamp = datetime.now().strftime("%Y%m%d-%H%M%S")
    b = BACKUP_DIR / f"{p.stem}.{stamp}{p.suffix}"
    shutil.copy2(p, b)
    return b

def replace_function(src, func_name, new_block):
    """Substitui função inteira via contagem de chaves (não regex guloso)."""
    pattern = re.compile(rf"(async\s+function\s+{re.escape(func_name)}\s*\([^)]*\)\s*\{{)", re.M)
    m = pattern.search(src)
    if not m: return src, False
    start = m.start()
    i = m.end() - 1
    depth, in_str, escape = 0, None, False
    while i < len(src):
        c = src[i]
        if in_str:
            if escape: escape = False
            elif c == '\\': escape = True
            elif c == in_str: in_str = None
        else:
            if c in ('"', "'", '`'): in_str = c
            elif c == '{': depth += 1
            elif c == '}':
                depth -= 1
                if depth == 0:
                    end = i + 1
                    break
        i += 1
    else:
        return src, False
    return src[:start] + new_block + src[end:], True

def main():
    src = TARGET.read_text(encoding="utf-8")
    log = []
    src, ok = replace_function(src, "nomeDaFuncao", """async function nomeDaFuncao(){
  // novo código
}""")
    log.append("✅ nomeDaFuncao substituída" if ok else "❌ falhou")
    if src != TARGET.read_text(encoding="utf-8"):
        b = backup(TARGET)
        TARGET.write_text(src, encoding="utf-8")
        print(f"💾 Backup: {b}")
    print("\n".join(log))

if __name__ == "__main__":
    main()
```
