⚙️ Setup único — 1 minuto

A função listar_schema() ainda não existe no seu banco. Roda esse SQL uma vez no Supabase e nunca mais precisa mexer:

  1. Abre o Supabase no navegador
  2. Vai em SQL Editor → New query
  3. Clica em 📋 Copiar SQL aqui embaixo
  4. Cola no SQL Editor e clica em RUN
  5. Volta aqui e clica em 🔄 Conectar e gerar
Clique em "Conectar e gerar" pra ler a estrutura do banco.

Se for a primeira vez: clica em "⚙️ Setup (rodar 1x)" primeiro.
